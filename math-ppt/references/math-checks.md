# 数学表达与核对

## 按内容类型检查最低完整性

下列检查针对本课实际包含的内容，不要求一节课覆盖全部类型。先检查数学内容，再按 [教学组织](teaching.md) 检查学生的学习过程；展示出完整解答不能单独证明教学有效。

| 内容类型 | 检查内容 |
| --- | --- |
| 概念与表示 | 对象、定义条件、适用边界和符号含义完整；例子与辨析不违反定义 |
| 计算与算法 | 适用条件、关键步骤、所用依据、结果及相应检验完整 |
| 定理与证明 | 已知、结论、推理链和关键依据对应，不能凭图形外观或少量实例代替证明 |
| 作图 | 已知与目标、工具、操作步骤、结果及满足要求的检查对应 |
| 应用与建模 | 量和单位、关系或假设、模型、求解以及实际解释与检验完整 |
| 数据与统计（本课涉及时） | 问题、数据来源及范围、整理表示、分析依据和结论边界对应 |

一条定义的讲解不必带完整证明，一道练习也不必重述所有知识；按该教学对象的任务检查，不机械给每页补齐表中全部字段。

## 定义和表示
检查定义所需条件是否完整，术语与符号一致。表示几何对象时核对点的顺序、顶点和射线方向。不能将几何图上的视觉印象直接写成已知条件。

## 题目条件与解答
逐问列清实际使用的条件，再检查推导能否由这些条件得到。选项、填空、小问、解析和最终结果相互对应。原题更换数字或条件后重新解答，不能沿用旧答案。

## 公式与识别文本
PDF文本可能出现分母丢失、上下标错位、特殊字体符号乱码、空白线被识别成数字。出现这些情况时核对原题图和页码，未确认前保留问题说明。

单靠识别文本里的公式计数不能判断有无公式。查看正文中的式子及图像，保证条件、等号、不等号和单位均能读清。

能从明确的原文、符号定义或已核对图片确认时，可规范空格和公式写法并保持数学含义。分子分母、指数、点名或关系符号不确定时不能凭“常见题型”补全。模型重新解出一个合理答案，也不能证明猜测的原题条件正确；缺少关键依据按主文件的缺失处理规则执行。

## 方程解答
设未知数并说明含义，用含未知数的式子表示数量关系，根据等量关系列式，分步求解，再检验并回答实际问题。判断数值是否为解时，代入比较左右两边。

所涉知识的成立条件必须逐条同时满足（如相关定义规定的次数、系数、取值范围等限制），其他条件按当前题目和定义逐一核对。

## 图形计算与作图
文字条件与图形标签一一对应。角度、线段关系和作图步骤必须有题中条件或已讲知识支持。作图结果、已知图形及辅助线区分清楚，题目要求保留作图痕迹时说明实际生成能力。

## 答案与解析
教师版答案也需要核对。明确数值、单位、符号、解释和图中标注是否一致。发现原答案疑点时提出具体问题，不把不确定结果写成已通过核对。

## 跨页一致性
同一道题的条件、点名、未知数、单位和答案在各页保持一致。前一页使用的知识与后一页推导衔接，课堂小结中的公式应与前文一致。
