# 页面制作

## 使用现有逐页接口
字段名称以当前运行时提供的 JSON Schema 为准。SlidePlan 包含整套标题、lesson_type 和 slides。新授课使用 new，用户明确要求复习或自定义结构时才使用其他课型。

每页写入 page、section、title、blocks 和按需填写的 speaker_notes。page 从1连续编号。教学页的 section 使用标准栏目名称，一个教学页只属于一个栏目。用户明确要求的独立封面是栏目之外的额外页，由外部制作程序单独添加，不混入当前仅承载教学页的 SlidePlan；封面要求可记在课题页 speaker_notes，不伪造 section 或新增 Schema 字段。SlidePlan 的 page 和页数要求均针对教学页；制作程序添加封面后须维护实际页码对应关系。title 写本页实际主题或任务。

kind、origin、material_ids、image_index、reveal_order 是组织和制作字段，不将字段名或“【内容】【步骤】【答案】”等机器标签逐块机械上屏。按用途可显示自然的“思考”“导引”“解”等教学提示，层次由版式、位置和强调区分；教师明确要求审查字段的技术视图除外。

### 学生可见标题与后台定位分开

默认不在课题、页标题、栏目或学生正文中显示教材章节和课时代码。带课时代码的标题改为对应的知识主题，如“〔课时代码〕＋〔知识主题〕”只保留后半部分；把课时代码拼进栏目名（如“〔课时代码〕课堂训练”）时，按该页实际任务另起标题。跨课时合并设计时用知识主题衔接，不展示“课时分界”等后台组织提示。

检索条件、原始资料和教师备注保留原编码及完整定位；不修改数据库名称或原文来实现上屏清理。保留原题必需的图号、例题号、小问号、页码序号和数学小数；先区分其用途，不能用删除所有数字编号的方式清理标题。用户明确指定的展示内容优先。

**上面这条只管标题和栏目，管不到例题出处。** 例题出处必须上屏可见；有真实课时代码时显示代码，没有代码时允许使用“教材名＋页码＋题号”，属于本规则唯一的例外，见下节；不按标题清理规则删除。

### 题号、出处与变式标注

上屏例题使用“例1、例2、例3……”明确编号，不只写“例”或“典例”。默认整套课件中的例题按首次出现顺序连续编号；同题的提示、讲解、答案和跨页续讲沿用同一编号，续页可写“例1（续）”，不把同一道题的每个页面编为新例题。原题的各小问保留并与解答对应。

例题编号后紧接可见出处，格式为“例N（〔实际教材名〕〔实际课时代码〕）”。示例仅说明格式，实际名称和编码必须来自已读取资料：资料只有某一级编号时就写该级，不得为凑格式编出更细的层级；没有课时代码时使用“教材名＋页码＋题号”，只填写实际提供且足以定位的信息，不编造缺失的页码或题号。需要精确区分时增加原栏目、题号或页码，如“例N（〔校本教材〕〔课时代码〕·〔原栏目〕例M）”。课件例题编号与原资料题号可以不同，后台引用与备注保留完整定位。

变式题写“变式N（由例M〔〔资料来源〕〔课时代码〕·〔原栏目〕例K〕变式而来）”等明确标识；基题未在本课展示时，直接写可定位的原资料题目，如“变式N（由〔教材名〕〔课时代码〕第Q题变式而来）”。不得只写“变式”“由教材变式”或把变式冒充原题。注明实际改动，如改变哪个已知条件、哪个对象的位置，可用简短上屏说明，完整改动及重新求解依据留在教师备注。完全自编题标“自编”，没有真实基题时不虚构变式来源。

沿用现有Schema：编号及简短出处写入title或题目前的question/text块，变式说明写入可见文本，material_ids和speaker_notes保留来源映射，不新增无法承接的source字段。

**出处必须学生可见，这是硬性要求。** 以下做法都不合格：

- 只写进 `speaker_notes`（备注里写“出处见校本××”也算不合格）
- 只写进 `material_ids`，指望后台追溯代替上屏
- 只写在教师版截图或图片里，页面上没有可读文字
- 写成“见原题”“同前”“同上”等无法定位的省略语
- 只在第一页标出处，后续续页省略

满足方式与字号：出处可紧跟在例题编号后同一行，也可置于编号之后单独一行，但必须是与题干同页显示的文字对象。出处按辅助标注字号处理（不低于18–20 pt，且不得因缩小而影响辨认）；例题编号、题干及学生必须阅读的变式条件仍遵守正文可读性要求。多页例题的每一页都要带同一出处的可见标注。

每个内容块按用途选择 kind：
| kind | 填写内容 |
| --- | --- |
| question | 学生看到的题目、选项、填空和小问 |
| hint | 解题方向或必要提示 |
| step | 一步演算、推理或作图说明 |
| answer | 最终结果或待揭示答案 |
| text | 定义、说明、归纳和小结 |
| formula | 独立展示的数学式子 |
| image | 对应图形，文字中说明用途 |

## 公式表示与制作能力

先按实际生成工具的参数契约确定公式格式；同一任务统一行内与独立公式约定，不混用工具不支持的定界符或语法。SlidePlan 的 formula.text 只是字符串，不能据此推定公式已转为可编辑数学对象。

只交付逐页方案、尚无渲染契约时，独立公式优先使用不加 `$` 或 `\\(...\\)` 外层定界符的 LaTeX 表达式；简单行内符号可用无歧义的数学字符。该约定仅用于方案表示，不承诺已有制作工具支持；后续工具规定不同格式时统一转换并核对数学含义。

JSON 中按语法转义反斜杠，例如表达式 `\frac{a}{b}` 写入 JSON 字符串为 `"\\frac{a}{b}"`，不要把转义字符误当成公式内容。上下标、分式、根式和条件不以随意拼接文字代替。

工具不能渲染时，只有在能保留数学含义并完成核对的情况下，才使用工具支持的替代表达或公式图片。不得静默丢弃公式、把原始代码当成完成的上屏结果，或在未验证时声称可编辑；制作能力不足与公式数学错误分别报告。原始识别文本的修复按 [数学表达](math-checks.md) 处理。

## 分步呈现
### 默认：初始隐藏，同页点击揭示

对需要学生先尝试的例题、训练、填表、判断及探究任务，初始只显示题目、必要条件和未泄露答案的图形，保留填空和作答空间。答案、解析、待归纳的结论和答案图初始隐藏，教师点击后再出现。普通短题默认在同页题目下方安排答案区，不默认另造一页答案，也不只把答案藏在 speaker_notes。

使用现有字段表达：reveal_order=0 是初始可见；hint、step、answer 及承担反馈作用的 text、formula、image 按实际教学时机写为1、2等正整数。同一步需要同时出现的块使用相同序号。判断是否泄露依据内容，不只检查 kind=answer；题干括号里的正确选项、填好的结果、红色解析、最终辅助线或完成图都可能提前泄露答案。原题明确提供的示范和已知条件保留，不误当答案删除。

### 题目、分析、答案三部分

采用带分析的例题或讲解题时，将同一道题组织成三个独立内容组，默认同页分阶段呈现：

| 内容组 | 默认 reveal_order | 呈现时机与内容 |
| --- | --- | --- |
| 题目 | 0 | 进入页面即显示题干、必要条件及不含答案的题图，留出学生尝试时间 |
| 分析 | 1 | 第一次点击显示简短的引导追问，帮助发现条件关系，不给完整解答 |
| 答案 | 2 | 再次点击显示解答、结论、计算结果及答案图，题目和分析仍可对照 |

这里的0、1、2只是单题默认示例，不是所有页面的固定阶段值，不作为顺序编码显示在学生页面。reveal_order 按全页的实际点击顺序统一编排；同一道题的答案必须晚于其最后一条分析。分析组必须使用可见的“分析”标题和边框容器，属于教学标识，不属于禁止上屏的机器标签。题目组、分析组、答案组必须能独立控制显隐，不把三组文字做成一张含完整答案的静态图片。同组内需要同时出现的文字、公式和图片使用相同 reveal_order。

#### 分析框的显示约定

所有实际安排的分析组均放入一个有清晰边框的分析区，框内左上方明确显示“分析”，其下排列本题的简短引导追问。不能只让几行提示文字突然出现，不能仅以文字颜色、阴影或“思考”替代“分析”标题和边框。没有分析组的题不生成空框。

初始态隐藏整个分析框，包括边框、底色、标题及其中所有文字或公式；到分析阶段时同步出现。实现时优先组合为同一动画对象，无法组合则各对象设置同阶段同时出现，不额外点击才能出现边框或标题。默认整框一次出现，不自行把分析拆成多次点击；只有明确的教学安排要求分步分析时，框与标题随首条分析出现，后续条目在框内按顺序显示，答案排在最后一条分析之后。

答案阶段到来后，分析框仍保留供对照；答案放在独立区域，不混入分析框提前显示，也不覆盖题干和必要图形。连续页讲解时，实际承载分析的页面同样使用分析框。静态审阅终态可显示完整分析框，但不能据此声称点击隐藏已验收。

沿用hint等现有字段表达分析内容，制作端根据分析组创建框和“分析”标题，不要求模型新增box或style字段，也不把边框写成题目文本。speaker_notes可说明框的位置与分步安排，但备注说明不能代替成品中的实际框线和标题。

分析内容来自资料库为每道题准备的两套材料，二者用途不同：

| 材料 | 内容 | 用途 |
| --- | --- | --- |
| 三层 PPT 引导 | 关键问题、递进提示、反思迁移 | 上屏分析组的内容来源，按题目的关键难点选用 |
| 五维详细分析 | 考点分析、条件分析、思路分析、难点分析、拓展分析 | 教师备课用的完整解析，不整段上屏 |

分析组优先使用三层 PPT 引导，按“关键问题—递进提示—反思迁移”组织；反思问题可先提出，待学生解答后再讨论，不在分析组预填其结论。五维详细分析用于理解难点和决定提示强度，不能原封不动堆到学生页面。也不能把操作指令加问号充当启发。采用哪些提示应结合题目的关键难点与学生任务判断；资料库没有本题对应的现成引导时，直接省略分析组，不依据五维分析或题干自行补写分析追问；教师讲解提醒可以留在备注，不冒充已有上屏引导。

沿用现有 Schema：题干使用 question，分析追问使用 hint；完整演算或证明步骤使用 step，最终结果使用 answer。formula、image、text 按其实际作用归入相应显示阶段。分析里的多个短追问默认同次揭示；确有教学需要时可进一步分步，但答案不得早于分析，完整解答也不能混入分析阶段提前出现。

变式题或没有可用分析的题可以不设分析组，使用“题目0 → 答案1”。变式若确有需要且已有合适分析，也允许保留三部分；不能为凑三组杜撰内容，不能因省略分析而让答案初始可见。

概念探究先显示对象和观察任务，再揭示待归纳定义与条件；已学知识回顾、已明确用于教师示范的已知结论不一律隐藏，但不能借示范名义让所有学生任务直接附带答案。

例如同一页：question（题干与不含答案的题图）为0；hint（针对本题关键关系的简短追问）为1；step（本页演算或推理）与answer（最终结果及达成答案的图）同为2。这分别是题面、首次点击的分析、再次点击的解答状态，不能把三组同时静态写入就称为已实现揭示。

### 数学复杂过程与表格

长计算、证明和作图可因必要中间状态或容量连续页展开，保留当前题干、条件和所需图形；每页尚待学生完成的部分仍初始隐藏。不得为了省去动画把所有普通题都拆为“题目页＋完整答案页”，也不得为了坚持同页而缩小字号、删减小问或推理。作图的新增辅助线、交点、弧和最终射线随步骤揭示，题面不能预先显示待作的完成图。

表格保留题目原有行列、已知项和示范项，待填答案按题或单元格顺序揭示，不能首次点击便泄露后续待答项。工具只有整块揭示能力时，应说明能力缺口，按每次反馈的题目分组安排可实现的内容块；未经实现不得声称支持原生表格逐格动画。不得为此编造当前 Schema 没有的表格或动画字段。

### 用图形变化表达数学过程

当学生需要观察位置、数量或关系怎样变化时，先确定哪一状态用来预测、哪一变化提供证据、哪一状态用于核验。同一对象跨步保留其定位依据，例如坐标轴与比例、顶点和基准线、数轴零点、表格行列标题。使新增点线、角弧、等量标记、图象或数据变化随实际教学步骤出现，并把量值标到所对应的对象。可直接比较的对象允许并列呈现；需要观察变化过程时，按制作能力选用有意义的分步状态、真实动画或课堂操作。采用课堂操作时在学生页给出操作和观察任务，在备注写明所需工具与示范动作。

制作前用实际的题面和最终状态核对版式。并列比较给对象留并列空间，图上操作给工具和标记留空间，推导为相关式子保留可同时对照的区域。对待作答任务，初始状态须具备独立作答所需条件，后续状态须能同时核对题目与反馈。

### 方案、静态审阅与实际动画分开

制作阶段须把 reveal_order 映射为真实点击动画，核对初始隐藏、点击次序以及答案出现后题目仍可读。仅有编号、颜色变浅、遮挡层或“点击显示”文字均不等于已经实现隐藏和点击。

只交付JSON或Markdown内容稿时，可完整保留解答供审核，但须区分“初始可见／第几次点击后显示”，不把审阅用全量内容当作学生首屏。静态PDF或预览标明是初始态、最终态还是连续步骤。用户明确要求静态步骤稿时可按顺序输出题面与反馈，仍不能声称有点击动画。

生成工具无法实现点击揭示时，明确报告未完成的能力及受影响页，不擅自改成首屏显示全部答案并称为合格；需改交静态步骤稿时说明交付形式差异，不能把降级当作已实现原要求。不把顺序编号当作已实现的动画效果。

### 同页多题的反馈顺序

默认逐题反馈，不把不同题目的分析或答案绑定为同次点击。各题题干可在初始态显示；按题目顺序依次安排本题分析、解答，再处理下一题。无分析时可用“各题题干0 → 第1题答案1 → 第2题答案2”；两题都有分析时可用“题干0 → 第1题分析1 → 第1题答案2 → 第2题分析3 → 第2题答案4”。同题同阶段的对象可以共用序号。只有用户明确要求整组反馈时才合并多题揭示。

## 复杂题拆页
保留判断当前步骤所需的题干和图形，长题可以保留明确的小问编号。每个后续页面交代正在处理哪一问，补充本页推导。换页不改变已知条件、点名、符号和单位。

若不同页面重复图形，其资料编号和图片下标应保持一致，新增辅助线或答案标记需有对应说明。

## 引用和图片字段
取自资料的块使用 origin=material，并填写实际读取的 material_ids。自编提问或变式使用 origin=original，并检查其数学正确性。

图片块引用一个资料编号并填写从0开始的 image_index。下标取自当前工具的确认结果，不自行编造文件路径或下标。text 描述图形内容和本页用途，便于审核题图关系。

### 先判断图形是否必需

不能只检查“已选择的图是否嵌入”，还要检查任务是否缺少应有图形。情境或装饰图可选；知识说明图应帮助识别对象；推理操作图必须支持相应观察、作图、判断或解释。要求“观察图中”“根据痕迹”“作出图形”的页面，不能只用题干和文字作法充当图形支撑。

多步作图按关键认知变化显示必要中间状态，如原角与交点、新位置的第一条射线和等半径弧、定位第二点的弧、最终射线。不要求每一步单独一张图片；可使用同图分步出现或有必要差异的连续状态图。只有最终结果图却看不清关键中间痕迹时，应补足。

对后续工具支持的SVG、原生几何对象或静态图片均可采用，但须真实可制作且可核对，不虚构当前Schema没有的状态字段或编辑能力。当前image块仍使用已注册资料的编号和图片下标；新图须先通过调用方支持的素材注册流程，不伪造原图下标。

若没有可靠原图或构造工具，按缺失规则查找替代或反馈能力缺口，不能默默取消必要图形、以“已插入示意图”冒充完成，或用外观相似的任意图代替数学关系。图形可以按已知条件新构造，但需区分原图与新图并核对关系。

### 对应页面与原图写入

制作角色根据 material_ids 与 image_index 解析真实素材，再把所选原图嵌入对应幻灯片；图片路径、引用文字、图注和备注均不能替代图片对象。图题放在能对应阅读的位置，保持比例及必要标注；不因省略页面渲染而省略图像写入。

同题跨页需要观察原图时继续嵌入相同素材，允许在PPTX包内共享资源，但每个需要的页面都要有实际图片引用。不得只插入一张到末尾“素材页”，让正文页缺图。

若调用方尚未传给制作阶段可解析的资料映射，或文件不存在，明确指出素材交接缺口，不自行编造路径、不静默改成纯文字版。制作工具不支持图片时如实报告未完成。仅交付SlidePlan时使用当前图片字段，不新增图片路径字段；不能把计划引用称为已嵌入。

含图Markdown审阅稿应在对应页使用可显示的图片链接，并保持随交付文件可访问；不能仅列一个无法打开的本机路径。若同时交PPTX，Markdown显示图片不代表PPTX已插入，分别检查。原图含教师答案的处理仍遵守 [资料使用](material-use.md)，不为满足插图要求泄露答案。

图号、内部资料编号、OCR状态和数据库路径放在后台审核信息中。speaker_notes 用于教师讲解提醒，不能代替学生必须看到的题干、定义或答案。

原题中学生需要据以作答的图号或小问号可以保留；这里不隐藏必要的题目指代。来源细定位允许使用教师备注，具体最小追溯要求见 [资料使用](material-use.md)。

## 页面完整性
例题页同时考虑题目、图形和解答如何呈现。练习保留空格与选项；答案按上述分步呈现规则初始隐藏、默认同页点击揭示。图中已有教师填答或解析时，先按资料使用规范处理，不能只隐藏答案文字块而让图片泄露答案。

表格和其他复杂对象以生成工具实际支持的形式提交。当前 Schema 没有对应字段时，不自行增加会被忽略的字段，也不把占位说明当成完成的图表。
