# 专项测试矩阵

## KnowledgeMap 专项测试

| 编号 | 检查 | 判据 | 验证方式 |
| --- | --- | --- | --- |
| TC-KM-01 | CORE目标覆盖 | 每个共同目标由CORE节点覆盖 | 单元测试＋语义审核 |
| TC-KM-02 | 知识关系 | 节点归属及关系方向具有数学依据 | 数据测试＋概念/计算/作图三课型人工案例 |
| TC-KM-03 | 页面追溯 | 非根节点有真实先前教学页，不用总结页自证 | 单元测试 |
| TC-KM-04 | 分层 | CORE不依赖可选节点，移除可选主体仍完整 | 数据测试＋双路径审核 |
| TC-KM-05 | 数据完整 | 唯一根、有效ID、无层级和前置循环、图谱页合法 | 单元测试 |
| TC-KM-06 | 数学正确 | 定义、条件、公式、结论准确 | 对照真实材料语义审核 |
| TC-KM-07 | 可读性 | 不缩字号、无溢出、连接线不穿字 | 容量预检＋真实文件视觉验收 |
| TC-KM-08 | 一致性 | 节点/关系均落盘，与实际讲授一致 | PPTX往返测试＋内容反查 |

后端项目的 `tests/test_knowledge_map.py` 覆盖两层与三层结构、关键拒绝条件及 PPTX 原生图形往返。表中其余项目按所列方式核验。单元测试结果限于结构与文件行为。

## 课时任务主线回归

按 [课时任务主线正反例](design-cases.md#lesson-task-thread-cases) 将方案交审核角色检查。核对是否指出具体页面或任务、给出证据与可执行修改，以及是否允许教学逻辑成立的对照方案。

| 编号 | 输入变化 | 通过判据 | 验证方式 |
| --- | --- | --- | --- |
| TC-THREAD-01 | 保留统一导入，移除中段的任务承接 | 识别主题包装，指出缺失的衔接；接受有任务产出的主线和有效的局部问题组织 | 人工对照或审核角色回归 |
| TC-THREAD-02 | 对关键易混淆规则只安排重复套用 | 识别缺少的辨析及必要反馈；允许有独立检验的直接讲授 | 人工对照或审核角色回归 |
| TC-THREAD-03 | 题面写出所有策略与步骤 | 识别缺少自主决定的位置，建议保留哪项选择，并核对基础路径仍有完整条件与反馈 | 人工对照或审核角色回归 |

## 指令违反回归

从满足规则的对照样例出发，每次只注入表中一处变更。记录对应规则、审核状态、实际证据和回流动作。反例应检出具体问题；正常对照应通过该项。需调用方日志、规则解析器或实际播放器的测试，依环境能力执行及记为未检查。

| 编号 | 正常对照 | 人为注入的错误 | 期望及证据 |
| --- | --- | --- | --- |
| TC-RULE-01 | 设计角色已加载数学核对与其余适用文件，加载记录可见 | 从本轮加载记录和上下文移除数学核对 | 不报告加载完整，指出缺失文件。按加载记录核对。 |
| TC-RULE-02 | 数学核对有实际页、小问和推导证据 | 将该项置为 NOT_CHECKED，仍提交总体通过 | 审核结论不能批准，定位需复核的规则和页面。按审核记录核对。 |
| TC-RULE-03 | 复习课由用户明确要求图谱，方案含合规图谱数据及图谱页 | 保持原始请求，移除图谱数据和图谱页 | 仍评估 MAP-001 并报缺失。对照原始请求及方案。 |
| TC-MAT-01 | 原题先解方程，再代回核验；方案保留两问 | 删除已选原题的代回核验小问 | MAT-001 定位原题缺失小问。对照选题和原文。 |
| TC-MAT-02 | 题干引用来自本轮已读取正文 | 把所用编号替换为本轮无法读取的编号 | 要求回查或更换可核对的资料。按实际读取得到的 ID 和正文核对。 |
| TC-TEACH-01 | 购票费用先试算，继续用于列方程和代回比较 | 保留购票导入，删除中间和结束对该任务的实际承接 | TEACH-001 指出失去用途的学生产出及衔接页。参见 TC-THREAD-01。 |
| TC-TEACH-02 | 为括号外负号提供可完成的局部改写和核对反馈 | 将提示替换成“适当引导”，保留其余任务 | TEACH-005 指出无法执行的支架及需要恢复的具体动作。检查题面与反馈。 |
| TC-TEACH-03 | 让学生根据带点名、射线与角弧的图辨认同一个角 | 移除题面引用的图 | TEACH-004 仍适用，定位缺少的图和学生依赖的信息。对照题面与资料。 |
| TC-CLASS-01 | 基础解题所需等式性质已在基础页说明，选讲另作方法比较 | 把求解必需的等式性质移入选讲页 | LAYER-001 指出基础页、被跳过页、缺少的依据及恢复位置。模拟仅基础路径。 |
| TC-CLASS-02 | 深入任务要求比较两种解法及适用条件 | 仅留下换数字的同类题，仍标深入选讲 | LAYER-002 指出认知增量缺失。允许同样题目明确作为可选熟练练习。 |
| TC-MAP-01 | 角的图谱各节点回指已讲的认识、表示或度量 | 增加本课未讲的角平分线性质 | MAP-002 指出节点和证据页不匹配。对照图谱及实际教学。 |
| TC-PPT-01 | 顺序放映进题页先见题面，点击后出现答案 | 移除实际答案对象的进入动画 | PPT-001 动态验收不通过。记录播放器、进入方式和初始状态。 |
| TC-PPT-02 | 方案选用的原图实际嵌入对应题页 | 从成品删除该图，保留路径或备注 | PPT-002 定位漏图及页面，回制作。核对具体图片对象与素材。 |
| TC-PPT-03 | 审核式子写明 x≠0，成品保留条件 | 制作时删除 x≠0 | PPT-006 指出条件差异，回内容核对并复查关联推导和答案。 |
