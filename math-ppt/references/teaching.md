# 教学组织

<a id="lesson-task-thread"></a>
## 课时任务主线设计（Lesson Task Thread）

核定课时范围和共同目标后，在编排页面前确定主要教学环节为何按这个顺序出现。课时任务主线为校本选题、局部问题链、分层和小结提供组织依据，沿用现有栏目和逐页接口。

1. **确定学生最终要做成什么。** 从共同目标提取可观察的学习结果。优先选择能服务多项目标、有明确数学意义的统领任务。学生应能用已学知识作初步尝试，且本课新学的知识能实质改善解决方式。可用纯数学问题。知识关系较弱时，采用若干有明确进展的局部问题，按真实的前置关系或教学用途衔接。课时范围由已确认的教材和校本依据决定。
2. **分解学习需要。** 对关键衔接，写清学生正在解决什么、已有办法能做到哪一步、还需要怎样的表示、依据或方法。让前一任务的结果或局限成为后一任务的条件、比较对象或新要求。学习需要也可以来自提高精确性、减少操作负担或解释结论。确无依赖的知识安排局部任务承接共同目标。
3. **在关键处让学生作出判断。** 对易混淆的条件、适用边界或方法选择，先安排可完成的比较、操作、推理或辨析，再依据学生可观察的结果归纳或修正规则。形式定义、术语约定和不宜自行发现的结论可由教师直接讲授，随后用辨析或应用检验学生能否判断适用条件。
4. **按教学作用选用校本题。** 判断候选题用于形成概念、检验边界、示范方法、练习局部步骤、比较策略还是综合应用。能承接主线的题优先用于相应环节，其他题可检验独立的共同目标。按资料规则保留已选原题的身份、条件和全部小问，改编与变式另行标明依据。
5. **安排自主运用。** 多个共同知识能够联合应用时，给出完整条件和可核验的产出，至少保留一项真实选择，例如先做什么、选用什么性质或方法、如何判断结果是否合理。帮助学生入手的提示可在尝试后揭示。适合局部方法课时，可用方法比较、条件辨析或迁移任务检验自主判断。
6. **检查基础路径与小结。** 跳过所有选讲后，基础必学仍能完成共同目标、必要任务与反馈。深入选讲可减少提示或增加解释和策略比较，拓展挑战可改变条件或安排推广与迁移。知识结构图按实际讲过的概念、依据和方法归纳，体现有教学证据的作用与关系；课时活动顺序可用于回顾，图谱节点应表达实际数学知识。

设计时用「共同目标 → 当前问题 → 学生判断或行动 → 新知识的作用 → 后续检验」回查页面。优先从实际任务和反馈呈现这些联系，按需在教师备注补充衔接依据。

## 从选用资料到教学活动

先按 [资料使用](material-use.md) 理解候选内容并决定用途，再编排栏目和页面，不要求先提交独立资料使用方案。资料目录的顺序不等于课堂顺序，资料有多少题也不决定必须讲多少题。

先以校本的知识回顾和选定题目组织主线，再将选用内容转为“学生任务 → 必要支架 → 学生表现或结论”。教材核对定义、性质并在必要处提供辅助探究；全解指导如何解释难点或补足方法。例题展示方法，同类题减少提示检查独立完成，变式检验迁移。按本课需要选择，不把这些用途另建为必需栏目。


需要教师示范的步骤写为实际提示与推导，需要学生完成的步骤先给任务再揭示答案。重难点应体现为学生可使用的具体提示、操作或反馈。

## 内容完整与学习过程分别检查

数学内容完整性检查概念、条件、依据、推导与结论是否正确完整；教学活动有效性检查学生是否有实际机会思考、操作、表达、验证或应用。完整的教师演示可作为示范，但不能独自替代核心目标所需的学生任务。

围绕核心目标建立“问题—方法—验证”闭环：给出学生需要解决的问题，通过探究或示范形成可用方法，再让学生尝试、解释、检验或迁移并获得反馈。闭环可由多个页面和不同题目共同完成，不要求每页完整重复，也不增加固定题数。

| 内容 | 适合的学生参与与反馈 |
| --- | --- |
| 概念建构 | 观察、比较、分类或归纳，用新例子辨析条件并说明理由 |
| 计算方法 | 先尝试或预测关键步骤，再分步推导，独立完成并代入、逆算或按条件检查 |
| 证明 | 寻找可用依据、补全关键推理、解释步骤之间的关系，检查结论是否由条件推出 |
| 作图 | 按任务实际操作或说明步骤，依据已知条件检查作图结果 |
| 巩固练习 | 学生先独立作答或表达方法，再展示对应答案与反馈；不能从首屏直接抄得结论 |

按教学目标与任务难点选择参与方式，不要求每项任务同时包含思考、操作、表达和验证。教师可以示范必要步骤，但应留有与核心目标相应的学生参与机会。

## 核心方法：从完成步骤到形成方法

先找出本课核心方法中学生不易理解的关键选择：为什么用这个条件、为什么确定这个点、为什么采用该变形。确有认知障碍时，围绕它组织递进问题，让学生观察、尝试、比较、判断或解释，再归纳规范步骤；普通熟练步骤不必逐一扩成探究。

每个保留的问题要有明确对象、学生行动和完成后新增的认识。仅将五步作法改成五个“下一步是什么”不构成方法形成；若只是回忆规范步骤，应诚实作为复习或练习，不冒充首次探究。

问题链可以跨页，前一问题的结果应成为后一问题的条件、依据或新的疑问。没有新认识、没有必要学生行动且只重复教师讲解的问题，可合并或删除；不得因此删去已选典例的小问。



## 学生行动与反馈

可按教学用途选用“提出任务—学生尝试—暴露关键问题—必要提示—补全或修正—依据反馈—应用迁移”中的必要环节，不要求每题固定七步。

题目给出后，安排具体可完成的行为与可判断产出：可以是标出本题的关键点、选择某个量的取值并说明理由、填写缺失的等式、补全下一步作法、画出结果或解释错误。只有“请思考”“与同伴交流”而没有对象和产出要求，不能单独算有效学生任务。

反馈回应实际任务：判断题说明决定性条件，补步骤题指出缺失依据，作图题说明应保留的痕迹和检查关系。核心任务遇到关键误区时，不只公布选项或答案，应说明错在哪里、怎样修正。不要预设学生一定会犯错，预计错误只用于准备反馈。

完整解析可留作后续反馈，但不能据此认为学生已经参与。题目和必要图先出现，学生有机会尝试后再提供适量提示、步骤或答案；默认初始隐藏、同页点击揭示。复杂过程的必要拆页、静态审阅与制作能力缺口统一按 [页面制作的分步呈现](page-model.md#分步呈现) 处理，不因工具缺少动画便直接显示全部答案。

### 从目标动词确定当堂检验

从每项共同目标反查已有任务。独立作答时保留解题所需的题干、图和工具，待学生首次给出答案或操作后，再揭示关键提示和反馈。示范结束后，可换一个对象或改变一个条件，观察学生能否自己作出关键选择。无需把所有检验集中到结束页。

| 目标 | 能据以判断理解的学生表现 |
| --- | --- |
| 辨认、分类 | 面对待判断材料作出选择；涉及条件辨析时，指出决定分类的特征。 |
| 解释、说明 | 把本题的具体条件与结论联系起来；可用口头回答或图上标记表达依据。 |
| 计算、求解 | 独立完成所考查的关键一步。若目标涉及方法选择，留给学生选择方法的机会。 |
| 作图、操作 | 独立完成相应动作，并依题设检查作图痕迹、位置关系或测量结果。 |
| 应用、迁移 | 在表示形式或情境改变后选用所学知识，指出新情境与已学方法的对应关系。 |

针对核心难点，想一想哪种回答只说明学生理解了部分条件。把核对依据放进作答后的反馈；必要时在教师备注写明听到这种回答后先追问什么、让学生重新检查哪里。学生面对的任务、条件和必要反馈仍落实到页面。普通熟练题可用简短答案核对。

### 从示范到独立任务

从校本候选综合题反推学生第一次需要独立作出的选择。若一道题同时要求选择表示、识别条件、操作工具或完成多步推理，先找出本课首次出现且容易出错的一步。检查学生之前是否看见过这一步怎样做、为什么这样做，并有机会在另一个对象上试做。支架可放进既有例题、小问或揭示阶段；已学会的技能可直接调用。核心目标的独立检验应保留到共同路径。

| 学生容易卡住的地方 | 可采用的支架与检验 |
| --- | --- |
| 概念与表示：同一对象有多种表示，或规则有适用条件 | 并列呈现能区分条件的对象，让学生指出图、式、表或语言之间的对应；换一个对象独立判断并说明依据。 |
| 运算与解法：综合题需要连续变换或容易在某步误用规则 | 示范一个关键变换，写清适用条件和检查方法；让学生独立选定下一步，再用逆运算、代入或量纲检验。 |
| 定理与证明：学生看到结论却找不到可用依据 | 给定图或条件，先让学生配对「条件—依据—可推出的结论」；再独立补一处推理，或判断缺少某个条件时能否继续推出。 |
| 作图与测量：工具摆放或先后顺序决定结果 | 展示工具与基准对象如何对齐，让学生预测关键落点、线条或读数；让学生操作，再按题设逐项核验。 |
| 数据与建模：学生容易直接套公式或误读图表 | 先标明量、单位、变量、坐标或样本范围；让学生提取一条有依据的关系，再在新数据或情境中独立解释结果。 |

页数有限时，优先保留能检验不同共同目标或不同易错判断的任务。相同操作的重复题可精简或保留为可选练习。深入选讲应有新的判断、解释或方法要求。已选典例的小问完整保留。

## 练习组织：能力递进与内容互补

选题后检查两个维度：后一道任务增加了什么思考、操作或自主要求；它检验了前题没有覆盖的哪些知识或能力。不是只有“更难”才是递进，也不要求难度单调增加。


任务作用应从实际题目、提示和反馈中可判断，不要求额外交选题分析表。是否保留一题仍由目标覆盖和课堂用途决定，不能为表现递进强行增题，已选典例的全部小问仍须完整处理。

## 探究真实性：六要素契约

只有实际设计为探究的活动，才用下列六要素检查其完整关系；不将其强加给课题页、目标页、所有计算步骤或普通独立练习。

| 要素 | 在活动中核查什么 |
| --- | --- |
| Question（问题） | 有明确对象和待解决的数学问题，不只是“想一想” |
| Action（行动） | 学生实际比较、计算、测量、操作、分类或表达什么 |
| Observation（观察） | 从行动中需要记录、发现或比较哪些现象和结果 |
| Evidence（证据） | 哪些数据、实例、图形事实或已知条件支持后续判断 |
| Reasoning（推理） | 如何使用证据和数学依据形成解释，区分猜想与证明 |
| Conclusion（结论） | 回答原问题，说明得到的知识及成立条件 |

六要素可以合并呈现或跨页完成，不需要把英文名称或六步标签放进学生页面。缺少会使推理链断裂的要素时修复活动，不能把普通问答强行改成六页。

检查是否真实保留了学生行动与思考机会：点击“显示答案”是呈现控制，本身不是探究行动；只有教师依次展示问题和结论也不能冒充学生探究。预设问题和预期回答可以设计，但未实际开展课堂时不能声称观察到了真实学生表现或已证明学习有效。

基于有限例子归纳出的规律按其证据强度标为猜想或待论证结论；六要素中的 Evidence 不等于已完成数学证明。形成方法或结论后，按本课需要通过辨析、应用或检查安排反馈。

## 课题页
上屏填写课题及必要教材信息，标题用知识主题，不以章节或课时代码命名。章节、课时及原始编码保留在教师备注和后台定位中；知识范围仍需准确，不能因隐藏课时代码就混入后续未要求内容。教师明确要求展示课时名称或编码时按其要求处理。

## 学习目标
放在导入之前，按编号列出本课要学习的知识和方法。后续探究、例题或练习要体现这些目标。目标写成学生能理解的具体内容，避免只写“提升能力”等空泛表述。

## 导入
使用与本课知识直接相关的问题，或回顾接下来需要使用的旧知识。导入页给出学生需要回答的问题。问题与下一页的探究形成联系，不引出随后不再处理的故事或数据。

## 新知探究
按“提出问题—观察或分析—数学表示—归纳结论”的先后组织实际内容，各步按课题需要取舍。
- 数量关系问题先交代量及其关系，再写代数式或方程。
- 定义先展示相关对象，再说明对象满足的条件及表示方法。
- 图形问题把文字条件、图形标记和数学关系对应起来。
- 计算和解法展示具体步骤，在需要处解释依据与注意条件。

提问需要有对象和任务，例如比较什么、表示哪个量、根据哪个条件继续推导。下一步给出相应分析，不能连续列出问题却没有结论。

### 设计首次学习的核心概念

1. 确定学生要理解的关键条件或关系。选择能让学生观察该条件的材料。辨析概念边界时，可保留其余条件、只改变一个关键条件；理解变化过程时，保留有意义的起始、变化和结束状态，便于学生比较。
2. 按实际揭示顺序检查首屏。学生应能据已给条件完成一个具体动作，如指出差异、预测结果、分组并给出理由。检查标题、颜色、预填项和图中标记是否提前给出了待判断的结论。
3. 揭示规范表述时，回指支持它的具体对象和观察结果。若首轮观察只能支持部分条件，可加入能区分两种判断的材料，让学生修正。人为约定可直接介绍；教师也可先给定义，再让学生独立辨析其适用边界。
4. 选择能表达数学变化的呈现方式：原图上增添标记、并列比较、实物操作、口头预测均可。按认知需要决定同页揭示或跨页衔接，保留原题出处与自编任务的区别。

### 按数学内容选择展开方式

保留统一栏目顺序，在新知探究内部按本课内容选用下列组织方式，不增加固定页数或新的必需栏目：

| 内容类型 | 展开重点 |
| --- | --- |
| 概念与表示 | 观察对象 → 比较与反例 → 提炼条件 → 定义或表示 → 辨析应用 |
| 计算与解法 | 问题 → 方法依据 → 分步演算 → 检验 → 易错点 |
| 定理与证明 | 已知与结论 → 探究关系 → 推理依据 → 完整证明 → 应用 |
| 作图 | 已知与作图目标 → 工具 → 操作步骤 → 结果和依据检查 |
| 应用与建模 | 情境 → 量及关系 → 模型 → 求解 → 解释与检验 |

多种内容可以组合，不为了套模板增加本课未要求的证明或建模任务。

## 例题与变式
例题放在新知探究栏目。先呈现完整题目，再提供必要导引，然后展示解答。题号、图示、小问和答案相互对应。

典例的选用和完整性按 [资料使用](material-use.md) 处理；长题跨页时明确当前小问，并保留各问需要的条件。是否增加例题由目标覆盖决定，不规定最低题数。

选择变式时明确改变的是哪个条件，以及本题要继续使用的方法。修改数值、条件或图形后重新计算和检查答案。多个例题分别承担当前知识的讲解任务，避免堆入重复题而没有展开讲解。

同题跨页保留题目身份和资料引用，每页增加新的分析、步骤或结论。按已读取资料确定定义、例题与练习的关系，不以题数或总页数代替教学覆盖。

## 课堂训练
在学生已经看到相应方法后安排同类任务，先让学生尝试，再展示提示和答案。题目要求与刚讲的方法对应。该栏目为**可选**：整套页数不足时可整栏省略，不视为内容缺失；省略时应由新知巩固承接同类练习，避免方法刚讲完就直接跳到小结。

## 新知巩固
整理本课需要进一步练习的知识。选择、填空、计算、应用题均需给出完整条件与对应答案。使用较复杂题时保留必要提示或分析，不用未讲解的新知识完成本课基础练习。

## 课堂小结
按本课实际内容整理概念、关系、方法与使用条件。分支、流程或文字均应把知识关系写清。只总结实际讲过的内容，不能在小结突然加入新的结论。

方法总结回指实际活动，说明用来解决什么问题、关键条件或不变量是什么、怎样检查结果，避免只重复操作清单。思想方法也应对应具体题目中的行为或关系，只列思想方法的名称（如“某某结合”“某某类比”）不能算作小结内容。

## 思想方法与结束页
思想方法单独成页，指出本课具体活动体现的方法，表述与本课题目对应。最后安排简短结束页。

## 页数与容量安排

逐页编排前估算教学页预算。按规定字号和真实内容核对题面及最终揭示状态，计入必需图形、题源、分析框、解答、Logo 与独立知识结构图的空间。有明确教学页数时，图谱计入该页数，独立封面按用户任务另计。

容量不足时按下列顺序评估可行调整：

1. 精简重复讲解及无新增教学用途的练习。
2. 需要腾出教学页时省略可选课堂训练，将必要检验安排到合规环节。
3. 减少非必要的深入选讲和拓展挑战。
4. 如仍超出容量，另选能覆盖同一目标且可完整呈现的校本典例，并重新核对全部引用。
5. 调整图文布局及必要的跨页安排。每张续页提供新的教学信息，保留所需条件和图形。
6. 仍无法满足时，指出缺口、冲突页或内容和可行的最小调整。

保留必需栏目、字号要求、关键图形和已选典例的全部小问。

## 共用课件的难度分层

执行 [共用课件的难度分层规范](difficulty-layering.md)。按本文件已有接口和职责承接实际任务、来源、页面及审核结果，不新增未支持的字段。

前置知识按实际教材与已学范围核对；操作或测量验证不能冒充严格证明。


用户明确要求的独立封面属于标准栏目之外的额外页，不计入指定教学页数，也不替代课题页。教学页按标准栏目编排，实际文件总页数另加独立封面页数。


## 本课知识结构图生成规范（KnowledgeMap）

实际教学内容确定后，再提取核心主题、一级知识分支和二级知识节点。候选类别包括概念、分类、表示、性质、方法、数学依据、易错与应用，不强制齐全或固定分支。节点与实际教学相互反查，拒绝目录拼接和无依据的关系。图谱在课堂小结中独立成页；数据与具体规则见 [KnowledgeMap](knowledge-map.md)。
