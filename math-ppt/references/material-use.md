# 资料使用

## 目标与处理流程

资料用于支持教学决策，不以提取文字数量或引用题数衡量使用效果。依次完成：定位资料 → 读取候选内容 → 理解知识与题目 → 判断教学用途 → 确定选用和改编 → 编排页面 → 核对来源与内容。

先用课时和目录筛选候选，再精读可能采用的条目；不要求每次深度分析全部题库。准备角色整理目录、范围和缺失信息；设计角色先理解内容和教学用途，再编排页面，可以回查原文、替换题目和修订决定。不要求新增智能体或输出独立资料使用方案。

## 校本主线与补充顺序

1. **先读校本。** 依据当前课时的知识回顾、课堂材料与作业材料确定主要内容及候选题，理解原题和教师解析，再安排讲解、训练与巩固。校本是主线，不是必须全部上屏的清单。
2. **教材辅助。** 针对校本涉及的概念、条件、符号和方法核对教材；校本缺少必要概念说明或探究时，优先从教材补足。不以“教材为辅”为由跳过已选内容的知识核查，也不为了教材活动齐全而搬入整节所有活动。
3. **全解指导补充。** 对尚未解决的难点、讲解断点、解法选择和易错情形，查全解形成提示、比较、方法解释或必要变式。无具体缺口时不额外堆题，不让全解目录取代校本课时主线。

补充内容应能说明“校本哪处需要补、为何用该来源、如何服务本课目标”。不强制按来源分配题数或页面比例，也不以实际引用次数判断是否以校本为主。

本课校本缺失或必要信息无法核实时明确说明，不能悄悄用教材或全解替代并声称遵循了校本。教师已要求必须使用校本时先补齐或确认替代；未确定的主线只能形成候选方案，不宣称定稿。教材全解未提供时如实记录，不编造其观点；其他资料足以支持本课时可继续设计。

## 从目录找到需要的内容
先按教材、章、小节和课时定位资料。目录中的标题、页码和图表数量用于选择下一步读取对象，不能单凭标题复述定义或题目。

有 load_teaching_materials 工具时先查询当前任务资料。需要更多目录条目时调用 list_materials，按返回的 total 和 offset 继续翻页。目录只展示部分条目不代表其余资料不存在。

## 各类资料分别使用
| 类别 | 用法 |
| --- | --- |
| 校本教材（主） | 理解课时安排、知识回顾、题干、小问、方法、答案和题图，据此确定讲解、训练与巩固主线 |
| 教材原文（辅） | 核对核心概念、成立条件、符号、前置知识和结论，补充校本缺少的必要说明或活动 |
| 教材全解（指导补充） | 参考解析、方法总结与易错辨析，解决具体讲解缺口，按需补充支架或变式，不替代原文或扩大课时 |
| 重难点分析 | 理解困难原因，转化为比较、反例、提示或中间步骤，并安排检验任务 |

资料类别为空时保留缺失信息。教师指定必须使用而尚未查到的资料，需要反馈缺失，不能编造为已查到内容。

教材全解与“重难点分析”是两类不同资料，按本次实际返回的类别名和来源区分，不将校本教师解析改称全解。两者都只作教学指导补充，不替代校本主线和教材原文。资料概览里没有该类资料时按缺失处理，不自行编造查询类别、资料编号或原文；只能使用实际已返回且来源明确的内容。OCR 未复核条目使用前必须核对来源图。

### 校本：从课时内容到教学主线

先读该课时的知识回顾和核心题，判断它们共同要求学生掌握什么，再决定内容的先后与选题。课堂手册和作业手册可互补，但不照搬原目录、不要求所有题都采用；先完成本课核心内容，再按目标和教学用途选择练习。

### 两种完整性

| 完整性类型 | 判断标准 | 是否必须满足 |
| --- | --- | --- |
| 知识完整性 | 本课必须掌握的知识、必要条件和核心方法均得到落实，每个核心教学目标有教学活动或内容承接 | 必须 |
| 资料使用完整性 | 校本资料中的所有栏目、题目和小问均被采用 | 不要求穷尽 |

本课校本知识回顾的每一项均须读取、核对，核心知识全部覆盖；可用解释、探究、例题或练习承接，不要求逐字抄到页面。发现某项与已确认课时范围冲突时列明具体冲突，不通过静默删去或改称“非核心”绕过覆盖。

典例精讲按知识代表性和教学价值选择，不要求全部选用；但选中的一道典例必须保持完整题干、条件和全部小问，并为各问提供相应讲解与答案，不能截取其中某问冒充完整例题。内容过长可跨页，不因页数或难度删问；整题不适合本课时更换完整例题或反馈范围冲突。这里的“资料不必全用”不解除已选典例的整题要求。

不能删除已选典例的小问后，仅通过改标 original 或改称变式规避整题要求。另行设计变式应有独立教学目的，明确改变的条件及与原题的区别；变式正确不代表原典例已完整讲解。撤换不适合的整道典例时，重新检查替代内容的目标覆盖。

训练题按方法覆盖和反馈作用选择，不用练习数量代替目标落实。同一目标可由不同题目承接，但重复题应增加新的辨析、独立完成或迁移任务，避免无意义重复。

即使只选一道题，也要能指出它覆盖哪些目标、哪些知识或方法仍需其他活动补足；一道题的多小问不自动代表覆盖全部目标。最终通过目标与实际教学内容的对应判断完整性。

### 教材：从知识依据到课堂任务

提取结论时同时核对条件和适用范围，区分教材原有结论与本次补充说明。保留符号含义和知识关系，不能只留下简短定义而删掉关键限制。

将观察、思考、操作等活动转成具体学生任务：观察什么、比较什么、依据哪些条件、需要得到什么结论。保留核心数学问题，可调整提问和页面顺序。已知结论不能替代学生应完成的观察与推理；不为每个概念强行增加探究活动。

教材活动只在支持校本主线、补齐必要概念或提供更合适探究时采用。教材有而本课校本未安排的后续内容，不因辅助查阅就自动纳入。

### 教材全解：从指导到补充

1. **定位缺口。** 从共同目标和拟选校本例题反查学生首次独立完成的关键一步，定位可能混淆的条件、易错操作、推理断点或方法选择。已有教学安排足以处理的内容可直接回指相应页或小问。
2. **按范围查正文。** 可用全解查询工具支持的教材、章、节、知识点和题型定位，优先回查与本课缺口相关的重难点、易错辨析和方法说明。首次关键词无命中时，换用本课知识的同义词、教材术语或较宽的章节范围检索，再按实际课时筛选。命中标题或摘要只算定位，采用前读取条目正文及必要上下文。使用待复核 OCR 条目前核对来源图。
3. **决定怎样进课堂。** 将适用内容化为具体页或小问上的解释、比较、分步提示、图形状态或反馈，并留下能定位原文的来源。可沿用已选例题或活动，在现有教师备注中简记后台出处。若已有活动足以覆盖，明确它在哪一步让学生做出相应判断或操作。
4. **处理查阅缺口。** 区分查无适用条目、资料或工具不可用、命中但原文待核对。判断是否能由校本、教材或经核验的自编支架处理。仍缺少影响数学正确性或核心教学目标的依据时，按技能的缺失依据流程处理。

设计自检可用「学生卡在哪一步 → 查阅结果或已有依据 → 页面和小问」逐项回查，保留必要证据即可。现有逐页方案和教师备注承载有用信息，无需新增台账、字段或交付件。

全解提供的新方法须核对前置知识是否属于本课；补充例题和变式按相同选题、改编和核验规则处理。保留实际来源，不把全解结论标成教材原文。全解答案和校本答案同样需要依据完整条件检查。

### 重难点：从诊断到支架

对本课实际需要处理的难点，建立“困难原因 → 教学干预 → 检验方式”的关系。例如条件容易遗漏，可用对比例或反例辨析，再让学生判断新的情形；步骤跳跃，则补充对应推导和依据，再安排减少提示的任务。

不把“易错点”原文直接贴成一页就视为已处理。无真实学情依据时，用作教学风险或待验证假设，不声称当前班所有学生已经犯过该错误。没有重难点资料时可提出有依据的教学判断，但标明是本次分析，不能冒充资料结论。

## 按课时选择校本题
存在 search_school_materials 工具时，按 lesson_code 查询，可继续按 source_id 和 column_name 筛选。区分课堂材料和作业材料，按原题用途选用典例、检测或巩固题。跨课时取题需要符合用户明确的教学范围。

选中目录条目后，用 read_material 读取完整题干、小问、条件、图形和教师解析，再决定使用位置。保持大题与其小问、解答之间的联系。

对拟采用的题目，先理解解题所需知识、主要方法、必要步骤、计算或推理负担、可能易错点，再判断用途。“典例精讲”等原栏目只是候选线索，不能代替判断；涉及本课知识但主要依赖后续技巧的题，不作为本课核心例题。

同时判断任务的图形依赖：图是情境装饰、对象说明，还是承担观察、操作、推理的必要信息。作图、图形关系辨析等任务不能因切块未列出图片就自动变成纯文字题；查找能支持任务的真实图形及必要状态，仍缺失时按关键依据缺失处理。

典例的理解与选用以完整大题为单位，小问之间的递进关系也属于其教学价值；选定后的各问都必须在方案中得到处理，不仅检查题干是否保留。

### 选用判断

先检查课时匹配、必要信息完整、数学内容可核对、知识范围合适、题图对应。关键条件不完整或答案存在疑点时先补充、重新推导或替换，不能因题目有趣而跳过检查。

通过后用简短理由判断：服务哪个目标、代表哪种方法、解决什么教学困难、是否适合本班、与已选内容互补还是重复。不固定打分，也不按资料出现顺序或数量选题。教材必要概念和条件不能因缺少趣味性而删去。

采用的题目承担明确作用：例题示范方法，训练检验刚学的方法，巩固检查知识联系，变式检验条件变化后的迁移。同题用于多个阶段时说明新增的学生任务，避免同一道题反复展示却没有新要求。

比较已选题目的能力要求与内容互补性，不仅按计算量或难度排序。完整原解析只是设计依据，仍需把题目转成学生可尝试、可反馈的任务；具体处理见 [教学组织](teaching.md)。

## 最小可验证的资料追溯

采用的定义、题目、图形和解析至少能通过本次资料编号及原文片段、题号、图号或原始页码定位；不是只有一个无法缩小范围的整本教材名称。原题须能追溯到完整题干、必要条件和全部小问，截图链接不能取代条件核查。

使用现有 material_ids、origin 和图片下标记录来源。资料读取结果已有的标题、题号、页码、图号和正文用于核对；同条资料较长时可在允许的教师备注中简短标明定位，不把数据库路径或后台编号放进学生正文。没有定位信息时明确缺失，不编造页码或题号，不擅自增加 schema 字段。

审核依据实际传递的页面和可读取资料，核对内容是否支持对应表述。自编解释和改编题不能冒充原文，改编后仍须保留可核对的原始依据与改变后的实际内容。

选用理由、教学作用、任务层级、改编和核验是设计判断，不要求额外交付独立 MaterialPlan、全量使用台账或未选题报告。可按需要用简短记录辅助设计；当前接口不保证保存或传递这些记录，最终回复仍按 SlidePlan 输出。需要正式分析选题、替换或资料更新影响时，再由调用方提供相应中间数据接口。

## 改编方式与核验依据

| 改编方式 | 允许的处理 | 核对重点 |
| --- | --- | --- |
| 原样引用 | 保留定义、题干、条件和公式，仅排版 | 原文、公式及图片完整 |
| 表达优化 | 分段或调整措辞，不改数学含义 | 条件、逻辑关系和符号含义不变 |
| 教学重组 | 将解析拆成问题、提示、推导、答案，调整呈现顺序 | 小问、步骤和答案仍对应，初始态不泄露答案 |
| 内容再创作 | 改数字、情境或条件，设计变式 | 重新解答，检查图形与条件，标为 original，不能冒充原题 |

忠实引用或重组的内容按当前接口标 material；自编导语、问题和变式标 original。混合内容尽量拆块，避免给整段自编推理套原资料出处。改编等级作为内部决定，不新增 schema 字段。

核验必须指出实际依据，区分原文核对、模型重新推导、工具计算、原图核对、人工确认和尚未核验。模型自查不等于工具验证；教师版答案仍需检查题干是否支持。只有实际运行计算工具才报告计算验证，只有确实核对图形才报告原图核对。不以公式计数或一句“已核验”代替检查。

## 多资料冲突处理

按内容冲突处理，不用“教材大于校本大于教师答案”简单覆盖：

校本优先决定正常选材路径，但不决定答案一定正确。教材用于规范依据，全解提供指导；数学正确性仍由完整条件和有效推导核定。

- 定义与解析不一致：核对适用条件和完整推导。
- 题干与答案不匹配：依据完整题干重新解答，不沿用原答案。
- 符号不同：可统一符号，但同步转换题干、图形和解答；防止点名或变量误对应。
- 难点判断超出本课范围：先核定范围，再决定是否需要该教学干预。
- 多种方法不同：分别核验，再按目标和前置知识选择，不因形式不同判错。

缺失信息不得补造为原始条件。无法解决的冲突保留具体待确认项；影响正确性的内容不定稿，能替换时选用可核对的资料。

## 读取正文和图片
正文出现图号时，先检查 read_material 返回的 figures。存在 find_figure 时用资料编号和图号查询唯一图片，得到 image_index 后再写入页面。不能用图片数组的第一项猜测题图。

图片路径仅用于定位文件。存在看图工具时核对点名、线段、射线、角标和题目条件。图号重名、图片缺失或无法唯一定位时保留待核对项，不随意换成另一张图。

### 图片与题目归属

在内部记录图片属于哪条资料、哪个原图号或题号、哪个课时。使用工具返回的路径和下标，不凭相似外观跨题借图。同一道题跨页讲解允许重复使用同一图片，保持引用一致；不实行整套课件图片只能出现一次的限制。

校本条目的图片0可能是含题干与教师解答的整题截图，其余图片是关联图形；按实际工具记录判断。保留原图与新增辅助线、着色或答案标记的区别，修改后的图须能追溯原图和变更说明。

无看图能力时，仍可准确定位和引用已建立映射的原图，但不得声称看过图或推断图中条件。需要图中信息才能确定题干、推导或答案时，补充已核对的文字说明、人工确认或更换为内容完整的题目；仅有图片路径不能解除该待确认项。

## 教师版的处理
教师版正文和截图可能已经填入答案，红字可能是答案、解析、图形标注或解题连线。先识别当前题目的学生任务，再分别组织 question、hint、step、answer。

完整教师截图可以用于教师解析或答案展示。初始练习页需要无答案题目时，使用已核对的学生题干和相应图形。去答案结果未经核对时，不将其称为学生版。

出现教师填答或解析时按下列顺序处理：

1. 优先使用已核对、不含答案泄露的关联图形，文字题干单独排版。
2. 若完整文字条件足以作答且无需原图，可重排题干并延后呈现答案；不能因此删掉必要图形条件。
3. 若原图不可替代且含答案，换用能承担同一目标的完整题目，或请求核对后的学生版，不直接把教师截图放在初始练习态。
4. 只在工具和核对能力均具备时去答案或重绘；无法可靠处理则保留具体能力缺口，不承诺自动修复。

红色线条或文字可能是题目条件、几何标记，也可能泄露答案；“删除全部红色”不是可靠的去答案规则。修改图像后须检查必要条件有无丢失及答案有无残留。

## 保留内容依据
教材定义、公式、原题、图形、答案和解析对应到实际读取的资料编号。original 表示本次编写的提问、导语、变式或练习，不等于免于数学检查。新变式需要重新核对条件、图形和答案。

资料编号在本次任务内使用，不将上一次任务的编号直接复制到新任务。编号和读取信息用于内部审核，不放进学生页面正文。

## 共用课件的资料分层

执行 [共用课件的难度分层规范](difficulty-layering.md)。按本文件已有接口和职责承接实际任务、来源、页面及审核结果，不新增未支持的字段。
