# 专项审核验证案例

本文件供专项审核与人工回归使用。课件设计以当前课时和已读取的资料为依据。案例中的学科内容、题值、措辞和呈现顺序仅用于检验审核判据。

## 跨章节案例：整式中的同类项

| 审核情形 | 应能识别的证据与处理 |
| --- | --- |
| 从材料形成条件 | 先比较 3x²y 与 −5x²y，学生可观察系数不同而字母及其对应指数相同。再以 3x²y 为参照，分别与 3x²z、3xy² 比较。让学生指出前者改变字母，后者保留相同字母和总次数但改变对应指数。归纳时回指三组材料。仅有第一组时，不能据此认定学生已辨清两个必要条件。 |
| 独立检验 | 给出 7ab²、−2b²a、7a²b，请学生找出同类项并解释余下一项为何不属于同组。前两项符合条件。要求学生指出第三项的对应字母指数有别，才能检验其解释依据。若首屏已用同色标出前两项，按答案提前泄露处理。 |
| 根据回答追问 | 若学生将三项全归为同类项，先请他逐项列出 a 与 b 各自的指数，再自行修正。若目标含“解释”，而设计只让学生核对所选序号，指出缺少解释机会，在原题补上理由即可。 |

## 跨内容验证：综合任务前的关键一步

| 场景 | 应通过的设计 | 应指出的缺口 |
| --- | --- | --- |
| 一元一次方程 | 先给含括号的等式，让学生独立判断括号外的负号如何作用，再进入需要去括号、移项和合并的完整题。 | 规则讲完直接公布完整解，学生没有机会用到该规则或解释符号变化。 |
| 全等证明 | 给图和条件，分步标出两组已知边及夹角，让学生选择依据并说明条件如何对应，再独立完成一题。 | 用动画显示全等结论和多组等量标记，无法区分题设、推导和待证明的对象。 |
| 统计图比较 | 先标明同类图的单位、刻度和起点，让学生读两个数再判断差值，最后换一组图独立说明。 | 只靠柱子的视觉高度比较不同刻度图，反馈只公布哪个更大。 |

## 课时任务主线正反例

以下案例用于人工或模型审核回归，按 [主线审核规则](review.md#lesson-task-thread-review) 判断。

| 用例 | 对照情形 | 应给出的审核判断 |
| --- | --- | --- |
| TC-THREAD-01 伪主线 | 一元一次方程课以两种购票方案的费用问题导入，随后只做等式变形，结束时重复购票背景。有效设计让学生先试算，再用未知数表达数量关系、列等式、求解并代回各方案核对。 | 前一设计缺少实际推进。指出从“试算”到“列式”缺失的问题，检查后续练习或反馈是否接续了原任务。后一设计有学生产出作为衔接证据。 |
| TC-THREAD-02 规则先行 | 同类项一开始就公布全部条件，之后只做机械合并。另一设计先给正式定义，再让学生解释为什么 3x²y 与 3xy² 不能合并，并用一组新对象独立判断。 | 前一设计缺少对相同字母与对应指数的辨析。后一设计的直接讲授和有依据的独立判断可以通过。 |
| TC-THREAD-03 自主选择 | 统计图综合题逐步指定学生读取哪两个数、怎样换算、得出什么比较。改为提供两组带单位和刻度的图，以及一条待判断的结论，请学生选择数据并说明判断依据。 | 前一题检验执行步骤。后一题保留了选取依据的真实决定，审核仍需核对图表条件和反馈是否足以支持判断。 |

局部问题的正例。绝对值课用数轴明确“到原点的距离”，随后让学生解释为什么相反数的绝对值相等，再用一题辨析绝对值等于零的情形。几个数学问题可以分别检验共同目标，课件无需另设贯穿情境。

## 分层设计通用验证案例

按 [分层规范](difficulty-layering.md) 人工或模型核查，不是自动测试结果。示意中的任务必须替换为实际数学对象，不将通用措辞直接用作学生题干。

1. 有效分层：基础任务提供必要提示并要求补全步骤；深入任务要求解释关键依据或比较方法，题面有实际对象，反馈有判断依据。不重复做同一道已完成题。
2. 无效分层：基础做一题，深入再做若干仅换数字的同类题，却无新增判断、自主要求或方法用途。应指出具体重复页并补充真实新增任务或精简。
3. 错误依赖：某选讲页首次给出必要依据，后续基础页直接使用。审核定位两页及所缺依据，将基础所需内容移回基础路径；只有非必需的进一步展开保留选讲。
4. 伪支架：仅写“教师引导学生思考”。应替换为具体条件整理、待补步骤或问题，明确学生产出与反馈，不直接泄露答案。
5. 同页控制失败：基础答案与选讲答案同时揭示。应拆分实际显示阶段，工具无法可靠控制时独立成页并更新继续位置。

验证记录：共同目标覆盖、真实任务增量、支架与反馈、原题完整、同页显示、跳过定位、前置依赖、深入路径、题号来源、标签一致。每项按满足／需调整／未检查／不适用，附实际页码及证据。至少用案例2、3、5验证审核能发现问题；未执行不填通过。内容路径检查不能代替动画播放或课堂效果验证。


## KnowledgeMap正反例

- 有效概念课：主题→概念分支→含必要条件的定义，分类分支给出分类标准；节点对应实际教学页。
- 有效计算课：方法分支→适用条件、操作依据、结果检验，不能将步骤顺序误标为数学推导。
- 有效作图课：作图目标→工具与步骤→检验关系，操作验证不冒充定理证明。
- 无效：把课题页、目标、例题、练习、小结作为分支；这是目录而非知识体系。
- 无效：所有节点写“概念/方法/应用”而没有实际内容；只加连线不能修复。
- 无效：图谱新增未讲结论，CORE节点依赖可选条件，或把父子关系画成逆向推导。
- 容量失败：把完整解析塞进一页并缩小字；应先提炼，仍不够则反馈而非自动拆页。
